# Daily Fresh

Premium grocery and chicken storefront using React, TypeScript, Vite, Tailwind CSS, Lucide and the existing TanStack routing setup.

## Local development

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
```

Includes six category collections, search, offers and combos, cart quantity controls and totals, chicken pack/cut preferences, favourites, PIN selection, demo login, mobile navigation, and policy/contact placeholders.

All prices and availability are sample data. State lasts for the current page visit. Login, delivery checking, real orders and payments are not connected to a backend. Chicken preferences apply to all quantities of that product in the basket.

The project remains connected to [Lovable](https://lovable.dev/projects/edfba2c0-db42-4bee-827e-466f5d3ec101). Preserve the existing configuration and published Git history when syncing changes.
